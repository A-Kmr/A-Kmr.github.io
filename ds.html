SQL patterns

Fast reminders for filters, aggregation, ranking, and common interview query shapes[cite: 3].

Core query patterns must know
WHERE
Filter rows before aggregation[cite: 3].
SELECT * FROM orders WHERE status = 'completed';
GROUP BY + HAVING
Aggregate first, then filter grouped results[cite: 3].
SELECT customer_id, COUNT(*) AS total_orders
FROM orders
GROUP BY customer_id
HAVING COUNT(*) > 2;
CASE WHEN
Create conditional logic inside SQL[cite: 3].
SELECT order_id,
       CASE WHEN amount >= 1000 THEN 'high' ELSE 'low' END AS amount_bucket
FROM orders;
CTE
Break a complex query into readable steps[cite: 3].
WITH monthly_sales AS (
  SELECT customer_id, DATE_TRUNC('month', order_date) AS month, SUM(amount) AS total_amount
  FROM orders
  GROUP BY customer_id, DATE_TRUNC('month', order_date)
)
SELECT * FROM monthly_sales;
